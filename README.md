# Blog-Post-Application
This repository is designed to work only in for INFO 251 assignment.

## Project Overview
This project is a lightweight, modular vanilla JavaScript application designed to display, create, edit, and delete blog post cards featuring tour destinations in Siem Reap, Cambodia. Built using standard HTML5, CSS3, and modern JavaScript ES6 modules, it demonstrates clean DOM manipulation and component state toggling without external frameworks or dependencies.
